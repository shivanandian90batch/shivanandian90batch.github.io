# பசுமைச் செயற்திட்டம் 2026 · Green Project 2026

Website for the Thirukkonrai (Cassia fistula) shade-tree planting project by the 2006 O/L / 2009 A/L batch
of RKM Shivananda National School, Kalladi, Batticaloa.

Live: https://shivanandian90batch.github.io

## Updating
Edit the `CONTACT`, `TREES` and `UPDATES` lists near the bottom of `index.html`.
Each tree's QR code links to `https://shivanandian90batch.github.io/?tree=N` (N = 1–12).
